# Ferns-and-Petals-Sales-Analysis
This project presents an in-depth sales and customer behavior analysis for Ferns and Petals (FNP), a popular gifting platform offering delivery services for various special occasions such as Diwali, Raksha Bandhan, Holi, Valentine's Day, Birthdays, and Anniversaries.

# Project Overview
The analysis is based on a dataset containing customer, product, order, and delivery details. The primary objective is to uncover key insights that can support data-driven decision-making, improve customer satisfaction, and optimize business operations.
